# Feeds

個人用の公開フィードを管理するリポジトリです。

現在は iCalendar（`.ics`）形式のカレンダーフィードを `calendars/` 配下に置いています。

## フィード一覧

| 内容 | URL | 状態 |
| --- | --- | --- |
| 決算予定 | `https://raw.githubusercontent.com/oshinko/feeds/main/calendars/earnings.ics` | 運用中 |
| ボクシング関連予定 | `https://raw.githubusercontent.com/oshinko/feeds/main/calendars/boxing.ics` | 準備中 |

## 購読方法

対象フィードの GitHub raw コンテンツ URL を、Google カレンダー、Apple カレンダー、Outlook などの外部カレンダー URL として追加します。

プライマリブランチは `main` です。
